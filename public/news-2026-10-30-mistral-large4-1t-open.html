欧洲万亿旗舰把权重全开了：总参 1.05T，每词元只激活 52B

API 预览跑了三周后，欧洲厂商把万亿旗舰的全套权重放了下来。对私有化部署的单位，重点不是又一轮跑分竞赛，而是三行字：下载下来的是什么、用什么装载、在什么条款下可以商用——这三行恰好都是选型文件里要逐字核对的。

一、官方口径先摆全

事项口径
总参 1.05T，每词元激活 52B，稀疏 MoE（细粒度专家混合）官方文档
上下文 1M；1.6B 参数视觉编码器；多模态输入、文本输出官方文档
约 2 个月从零训练，用 4,000 颗 Grace Blackwell，语言 160+ 种（含欧盟全部官方语言）官方宣称（厂商口径）
权重格式：FP8 与 NVFP4官方发布
API 标价：输入 $0.7 / 缓存 $0.07 / 输出 $2.1（每百万词元）官方文档

二、激活参数量为什么有两个数

媒体口径常写「49B 激活」，官方文档写 52B——按仓库标注 A52B 处理：差异出在骨干与嵌入、路由部分算不算进「激活」。选型表里遇到这种同一事实两个数的情况，照旧把两栏口径并排放，别取平均。

能力位次同理：厂商自报成绩与第三方评测口径有差距，本站已发布的 Intelligence Index v5 独立口径篇覆盖过对比方法。本文只把「权重可以下载」这一条当作已核实事实，能力位次请各家用自己的任务实测。

三、许可里比 MIT 多出来的那句

  • 允许使用、修改、微调、商业化——这条对绝大多数私有化单位够用；
  • 把模型作为「模型即服务」对外转售 API 的，需要另签商用协议——先弄清内部推理网关算不算「对外转售」；
  • 自托管的真实门槛在装载侧：FP8 全量与 NVFP4 都是多卡/统一内存级方案，端侧要等社区量化生态成熟，这条要写进排期而不是当既成事实。

选型文件里给这尊权重留三行

四条：

  • 第一行写「下载得到什么」：FP8/NVFP4 两种格式与 1.05T 体量，对得上你们的机房档位再谈；
  • 第二行写「条款」：Ecosystem Open-Weight License v26.10 的 MaaS 转售条款过一遍法务；
  • 第三行写「口径」：自报分数与独立评测分开列，激活参数 49B/52B 两个数都带上出处；
  • API 标价 $0.7/$2.1 只作外采对照线，自建 TCO 另起一栏，不互算。
