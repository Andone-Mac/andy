中国DeepSeek把App装进API：五类对话能力、五个独立接口，官方称可1:1复刻

11月13日周五晚间，DeepSeek官方公告开放「全家桶应用API」：App的联网搜索、深度思考搜索、文件输入、阅读链接、模型安全五项交互功能整合进原有API，开启对应参数，工具调用与上下文拼接由服务端完成；语音等底层能力同步开放Search、Fetch、OCR、ASR、TTS五个独立接口，单独调用、分别计费。官方说法相当直白：开发者可在自己的应用里1:1复刻出完整的DeepSeek App。

一、五类对话能力，一次开全

本次更新把 DeepSeek App（含网页端）的各项交互功能直接整合进原有 API。目前 V4.1-Flash 模型（模型名 deepseek-flash）已在 Messages、Responses 与 Chat Completions 三类接口下支持以下能力，开启对应参数即可：

  • 联网搜索：非思考模式下打开 deepseek_web_search 工具，模型根据提问自动发起网页或图片搜索，并附引用作答。
  • 深度思考搜索：思考模式下打开同一工具，模型可在多步推理中自主联网搜索与阅读链接。
  • 文件输入：支持上传 PDF、Office、图片等格式文件，服务端完成纯文本提取或图文混排解析后拼入对话上下文。
  • 阅读链接：打开 deepseek_read_url 工具后，模型自动识别消息中的链接，抓取网页内容并结合上下文作答。
  • 模型安全：开启安全校验参数后由官方提供基础风控，审核输入输出，命中风险时返回拒答标识。

二、五个独立接口与明码标价

底层能力不必打包使用：Search（搜索）、Fetch（抓取）、OCR（文字识别）、ASR（语音识别）、TTS（语音合成）均可作为独立接口接入自有工作流。DeepSeek 同步公开了工具定价，在 token 费用之外对工具调用单独计费。

接口计费方式价格（人民币）说明
Search / Fetch按成功调用次数5 元 / 千次10 月 17 日已先行开放，价格延续
OCR 文字识别按页1.5 元 / 千页折合约 0.0015 元/页（本刊计算）
ASR 语音识别按小时0.39 元 / 小时原价 0.78 元，限时五折；约 0.0065 元/分钟（本刊计算）
TTS 语音合成按万字符1.5 元 / 万字符原价 3 元，限时五折

价格明细为量子位 11 月 14 日报道对官方价目表的转引，「语音类限时五折」的说法另有钱江晚报与财联社佐证；五折期限官方公告未写，报价模型里建议按原价回收。

三、官方打了个样：开源 Demo 可导历史对话

为演示新版 API 的实际效果，DeepSeek 基于全家桶构建并开源了一套轻量前端（仓库 deepseek-ai/chat-demo，体验入口 cdn.deepseek.com/chat-demo）：完整演示联网搜索、深度思考、文件图片上传、朗读回答、语音输入、Markdown 与 Mermaid 图表渲染，支持直接导入 DeepSeek 历史对话续聊；API Key、历史对话和图片都保存在浏览器本地。官方公告里还有一句耐读的话——「DeepSeek 现有的对话产品只是较为基础的一种形态」。

四、和私有化部署搭界的三件事

  • 义务声明写进了公告：官方要求对外提供应用服务的项目开启安全校验参数，并承担内容安全审核、大模型登记、AI 标识等义务——登记与备案怎么并账，见本站同日发布的一篇《四类备案并成一本账》。
  • 搜索与抓取是云端能力：联网搜索、网页抓取、云端文件解析都由 DeepSeek 服务端完成——对「数据不出内网」的场景，这套全家桶提供的是参考架构，不是可离线交付的组件。
  • 应用层复刻成本确实降了：此前做一个能听、能看、能查的企业助手，要分别对接语音识别、语音合成、OCR、检索四五个供应商；现在单厂商打包计费，留给集成方的工作量收敛到业务系统对接与模型选型这一层。

机悟建议

把「1:1 复刻 App」上项目预算表之前，先过四问

  • 数据边界先划：哪些功能允许走公网 API、哪些必须内网闭环，划完再决定接哪几个接口——这一刀决定方案形态。
  • 两本账分开算：token 费与工具调用费（搜索抓取按千次、语音按小时）是两张账单，按你们的月活与调用量做预算，别只看模型单价。
  • 限时价别写成长期价：语音五折未公布截止日期，成本测算按原价留安全垫。
  • 合规动作提前对齐：对外服务的功能，官方点名要求开安全校验并履行登记、AI 标识义务——上线前把备案台账一次核清。
