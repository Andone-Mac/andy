跑大模型要不要换 x8/x8 主板？双卡 2×16G 实测机器，先算四条管路

有人问：这台双卡机跑大模型，是不是该换一块 x8/x8 主板「大幅提高」性能？这个问题问得好，但它预设了瓶颈在槽宽。本文把本机三条已发布的实测链（11-08/09 单卡扫参、11-10 双卡改造与四档终版、11-11 三选项闭环）里的带宽读数，和今天用 dmidecode/lspci 取证的板级事实摆进同一张算式：谁在封顶、x8/x8 能修哪一段、修完值多少钱——顺带把 2026 年 11 月的配件行情贴进来，因为升级决策一半是技术问题、一半是周期问题。

一、问题与结论：先回答，再给算式

问题原样：这台双卡机（RTX 5080 16GB ＋ RTX 5070 Ti 16GB、128GB DDR4）经过三轮调优定型后，跑大模型要不要换一块能让两张卡两块卡都能各走 8 条 lane 的主板，以求「大幅提高」？

  • 结论：不换。x8/x8 修的是本机第三条瓶颈——第二张卡那条 7.2 GB/s 的窄腿；它修不动前两条真正的大头（显存容量、内存通道数），而且在这颗 CPU 上「换 x8/x8 主板」实际等于换整个平台。
  • 值多少：双卡长提示预填充的 37.8% 惩罚（本页第四节算式）会大幅收窄、高 miss 档与冷加载有感——但日常档解码收益接近零，因为那块已经不看槽宽。
  • 多少钱：消费平台没有现成的 x8/x8（Intel 桌面根本不给），迁移要连 CPU＋主板＋DDR5 一起换——按 2026 年 11 月行情约 两万元级（第六节，含出处），相当于本机 GPU 部分重置成本的一半以上。
  • 不花钱的同类收益还留着两个（第七节，已在跑）：热专家向快腿卡再平衡——用参数绕开窄腿，而不是花两万修它。

二、家底取证：板级事实与官方规格对质

先用 dmidecode 与 lspci 提权实读本机（2026-11-11），再对照华硕官网板规。一句话：主板没有骗人，插槽也没插错——是平台没有更多 lane 可给。

官网板规（ASUS baseboard)）：扩展槽为「1 x PCIe 5.0 x16 slot (CPU) / 3 x PCIe 4.0 x16 slots (support x4 mode) / 1 x PCIe 3.0 x1 slot / 4 x DIMM Max 128GB DDR4 双通道」——除第一个槽外，其余全长槽全部只电气 x4。也就是说：不换主板，本机无论如何到不了 x8；想 x8/x8，只有整平台搬迁一条路。这组板规还有第二个推论：三个 x16 外观槽都挤在芯片组（PCH）的管道上，而 PCH 与 CPU 之间只有固定的一条 DMI 总线——就算全插上，聚合带宽也不会叠加出奇迹。

三、四条管路：谁在封顶，谁有余量

这台机器上「跑模型」的字节流只有四条管路。引擎每次冷启动会实测一次「主机→显存」带宽（11-10 双卡改造篇逐轮记录在案），理论值按协议公式现算，两相对照：

管路宽度（实测/理论）谁说了算
NVMe → 内存（加载模型文件）Gen4 x4，理论 7.9 GB/s冷启动头几秒；加载总时长里 NVMe＋解包占大头
内存 → 5080（第一腿）引擎实测 36.8~44.3 GB/s（逐轮波动）冷专家流主路——瓶颈不在槽：Gen5 x16 理论 63.0，实测只有它的 70% 上下；DDR4-3200 双通道理论 51.2 才是墙
内存 → 5070 Ti（第二腿）引擎实测 恒定 7.2 GB/sx4 Gen4 理论 7.9——槽就是墙，这条腿是全场唯一「加宽即提速」的管段
卡 ↔ 卡无 NVLink、无 P2P（nvidia-smi topo：PHB），全部经主机内存中转双卡分工越「对半切」，中转账越贵——这是双卡长提示变慢的根

再加一条对照：w4a4 实验轮（11-11）在 NVFP4 双卡冷流下实测 PCIe 过卡 41.0 GB/s——同样贴着第一腿的内存墙。至此可以给出本节的判据式：一条腿「带宽已满、加宽无用」，一条腿「槽宽即上限」，第三条腿走内存要交双份过路费。

四、为什么日常解码「不关心」你加宽槽位

把 11-10 终版四档矩阵摊开看解码与命中率的对应（解码/命中率取 8k~131k 四个长度档，引擎 0.1.59）：

档命中率区间解码 tok/s 区间专家总量
IQ3_S86.9~90.9%106.4~111.377.9 GiB
NVFP486.9~92.8%79.6~124.972.3 GiB
IQ4_XS66.5~81.3%45.8~78.687.2 GiB
Q4_K_XL54.8~62.8%37.2~38.6103.7 GiB

规律一眼可见：解码跟着命中率走，命中率跟着「专家总量 vs 显存」走。IQ3_S 专家最轻（77.9 GiB）、命中率 87~91%，日常解码 106.4~111.3 tok/s；Q4_K_XL 专家 103.7 GiB、命中率跌到 55~63%，解码就只剩 37~39。缓存命中意味着这一层的专家已经在卡上、根本不用过任何管路；miss 的那一小部分才轮到 PCIe——而它先撞的是内存墙。这也解释了 11-10 双卡 vs 单卡的账：就凭这条 x4 窄腿，双卡照样把单卡定档 81.6 tok/s 推到 106.4~111.3、命中率从 79.4% 抬到 87~93%——窄腿不是没用，是「够用」。

五、把「换 x8/x8」逐项定价

能核实的实测锚先钉住：双卡对长提示的惩罚是现成的——同一探针、11-10 页记录，66,512 词元文档单卡预填充 2,156 tok/s、双卡 1,569 tok/s（-27.2%）；11-11 闭环轮里 Q4_K_XL 真 131k 单卡 1,451.6、双卡分层 903.0（-37.8%）。这两笔惩罚的根都在第二腿 7.2 GB/s 与内存中转上。把第二腿加宽到 Gen5 x8（理论 31.5 GB/s，现值约四倍）后，按搬运时间线性外推（下表「估算」列，未实测）：

负载现状（实测）x8 Gen5 后机理
日常解码（IQ3_S/NVFP4 高命中档）106~114 tok/s<3%（日常档 miss 流量小，瓶颈=命中率与 GPU 计算）miss 流量小，宽窄腿都不在关键路径
双卡长提示预填充惩罚 -27.2%~-37.8%-27%~-38% 惩罚收窄到 -5%~-15%（第二卡腿 7.2→~28 线性外推，估算）第二腿搬运收窄
高 miss 档（Q4_K_XL 类）命中率 55~63%%+10~20%（高 miss 档，带宽占比最大，估算）miss 流比例最大、带宽占比最高
冷启动加载29 秒 / 44~60 秒-15~25%（加载大头在 NVMe 与打包，估算）NVMe 与打包占大头
  • 注意一个反直觉推论：对「单卡常驻型」用法，x8/x8 收益恒等于零——第一腿本来就用不满内存墙。换平台的钱，买的是「把第二腿从 7.2 修到 ~28」这一件事，外加（若迁 AM5）DDR5 双通道理论 96.0 GB/s 把内存墙本身抬高。
  • 还有一个平台细节别漏：Intel 桌面 CPU 只有 16 条 GPU lane 且不给 x8/x8 拆分，「换 x8/x8 主板」在 LGA1700 上是伪选项；AMD X870E 系双 Gen5 槽同用各 x8 的机型也要看 M.2 占用（华硕规格页原文：启用 M.2_3 则退成 x8/x4）——升级清单里写「x8/x8」四个字，实际能拿到多少条，要逐板对表。

七、还不开钱包的话，先把免费的吃完

本机的窄腿是「第二卡上放了多少热专家」决定的——把分工改成「越热的层越往 Gen5 腿的卡上放」，同样的硬件就能少过窄腿。我们已在跑两组冷启动 A/B（探针与 11-10/11 同协议、现网实例全程分离）：

  • K-split 不对称重平衡
  • ：把双卡分层比例向快腿卡倾斜，测长提示预填充惩罚（-27.2%~-37.8%）能收窄多少——直接打第五节那两笔已核实的惩罚。
  • --expert-cache-device1
  • ：引擎日志给过的备选架构，把专家缓存固定到指定卡上——若语义是「缓存跟快腿走」，高 miss 档（Q4_K_XL 类）应最先受益。
  • 两组结果出分即按同一口径补录本报告与启动器默认；若实测收益 ≥ 一档惩罚的收窄，「换主板」的必要性会再降一层。

至于真正的下一跳，本号早已给过判据：这台机器的升级次序是显存容量 → 内存通道数 → 槽宽。第一位（48~64GB 显存把 NVFP4 的 72.3 GiB 专家基本装下）现在被周期锁着价——5090 渠道 高点约5万回落至约4.6万，比上市首发贵近两到三倍；最理性的动作是继续把参数和分工榨完，同时把「内存价格回落」设成盯梢项：按 快科技（转网易） 的口径，「2027 年趋稳」已是目前能找到的最乐观表述，而短缺信号指向 2028~2030。结论不变：这台机器现在不该为 x8/x8 花那两万；该花的钱在三年周期的下半场。

要不要为 AI 换平台？

按实测算式记，不按传闻记（2026-11-11，全部数字脚本现取）

  • 先量瓶颈再谈升级：给第一张卡加 lane 是 0 收益——它的冷流实测 36.8~44.3 GB/s，已经贴着 DDR4 双通道 51.2 GB/s 理论值的墙；给它加宽内存通道才有效。
  • x8/x8 只修第二张卡的窄腿（实测 7.2 GB/s）：值「双卡长提示惩罚收窄、加载快两成」，不值「大幅」二字。
  • 消费平台改 x8/x8＝整平台搬迁：Intel 桌面根本没有 GPU 用 x8/x8 拆分，要迁就得连 DDR5 一起重买——正处 DRAM 超级周期顶点（行情见文），约两万元。
  • 这台机器真正的大头杠杆是显存容量与内存通道数；在那之前，还有两项不花钱的参数实验（热专家向快腿卡再平衡）正在跑。
