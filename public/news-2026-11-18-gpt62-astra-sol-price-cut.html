2026-11-18大模型 · 云端 API

OpenAI 发布 GPT-6.2 双模型：旗舰 API 降价 20%，日常版 Sol 编码只差 0.5 分、成本约 1/5

11 月 17 日，OpenAI 发布 GPT-6.2 Astra（旗舰，面向科学、法律、金融等专业工作）与 GPT-6.2 Sol（日常高效版），同步上线 ChatGPT Work、Codex 与 API。Astra API 价格较上代降 20%（输入 $8/百万 token、输出 $40/百万 token），Sol 维持 $2/$10 不变。官方称在 FrontierCode 2.0 编码基准上，Sol 与 Astra 仅差 0.5 分、成本约为其 1/5。云端 API 的「每任务成本」之战再升级，本站此前 GPT-6 与 GPT-6.1 两篇可作背景。

一、价格表：旗舰降 20%，缓存输入降 60%

模型输入（$/百万 token）缓存输入（$/百万 token）输出（$/百万 token）
GPT-6.2 Astra8.000.4040.00
GPT-6.2 Sol2.000.1010.00

官方口径：Astra 标准输入/输出价较 GPT-6 Astra 降 20%；据 Artificial Analysis，缓存输入从 $1.00 降至 $0.40（降 60%）。Sol 沿用 GPT-6.1 Sol 价格。本刊计算：按「100 万输入 + 100 万输出」的粗账，Astra 一次 $48、Sol 一次 $12，Sol 是 Astra 的 25%。

  • 可用范围：Plus/Pro/Enterprise/Edu 用户在 ChatGPT Work 与 Codex 可用；API 模型名 gpt-6.2-astra / gpt-6.2-sol。
  • Ultrafast 模式官方称最高 4.5 倍出字速度（9to5Mac 引 OpenAI），Pro-200 档首次开放（先 Sol），Pro-500 档双模型可用。
  • GitHub Copilot 同日上线双模型（Pro+/Max/Business/Enterprise，MLQ 引 GitHub changelog）。

二、能力口径：Sol 逼近旗舰，Astra 主打专业交付

官方给出的关键对照：FrontierCode 2.0（检验代码改动能否达到真实项目合并标准）上，Sol 与 Astra 差 0.5 分、成本约 1/5（双方均开最大推理档）；LifeVal 日常任务基准上，Sol 超过 GPT-6 Astra、成本约 1/7。Astra 主打专业交付物——幻灯片按模板复刻版式、配色与字号，表格与文档更贴合行业惯例；官方称其在 Vals Science Index 创新高。

第三方口径：Artificial Analysis 智力指数上，Astra 升至第 2（仅次于 Claude Fable 5.2），较 GPT-6 Astra 提高 5 分，超过 Gemini 4 Carbon（60）与 Claude Opus 5.5（59）；Sol 得 57 分（+2），每任务成本约为 GPT-6 Astra 的 15%。

三、网络安全能力与护栏同步收紧

OpenAI 官方 X 账号称，Astra 在 ExploitBench Internal Port 上较 GPT-6 Astra 提高 22 分，是其「迄今最强的网络安全模型」；因能力增强，发布时同步收紧高风险网络安全协助的护栏，并计划通过 Daybreak 向经审核的防御方开放更少拒绝的访问。注意：公布的网安基准数字来自关闭护栏与分类器的内部测试（The Decoder 梳理），不能直接当作线上服务表现。

四、对企业的账：每任务成本，不是每 token 单价

这轮发布的关键词是「用更少输出 token 完成同样任务」（官方口径）。对企业采购，比较口径应从「每百万 token 单价」转向「每任务成本」：Sol 用约 1/5 的钱拿到接近旗舰的编码质量，意味着大量日常开发与文案任务不必再为旗舰溢价买单。但云端 API 再便宜，数据出境与合规边界不变——涉密与核心业务数据仍要留在内网，云端适合做非敏感任务的效率补充。

机悟建议：GPT-6.2 时代的云端与内网分工

便宜的是 token，不变的是数据边界

  • 日常任务换 Sol 档：编码/文案/摘要类非敏感任务，用 $2/$10 档先跑，旗舰留给硬骨头。
  • 按任务算账：用真实任务统计「每任务输入/输出 token」，再比单价，别只看牌价。
  • 缓存输入是大头：Agent 用法大量命中缓存（$0.40/$0.10），提示结构稳定能显著压成本。
  • 敏感数据不出域：核心业务与涉密数据仍走内网私有化模型，云端只做非敏感补充。
