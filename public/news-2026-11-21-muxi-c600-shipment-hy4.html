2026-11-21国产 GPU · 训推一体

中国国产 GPU 沐曦 C600 大规模出货：通过安全可靠测评，率先完成混元 Hy4 Day 0 适配

国产 GPU 的供给放量，又添一个实锤。据新华财经 11 月 20 日报道，沐曦股份在投资者关系活动中披露：新一代 AI 训推一体旗舰 GPU C600 已大规模出货，基于国产供应链，型号 MXC600 已通过国家安全可靠测评，面向智算中心、金融、能源、政务等场景。紧接着 11 月 21 日，证券时报·e 公司（人民财讯）报道：腾讯混元 11 月 20 日开源 Hy4，沐曦曦云 C 系列 GPU 率先完成 Hy4 的 Day 0 适配，实现高吞吐、低延迟稳定运行。一边是硬件放量与合规背书，一边是主流开源模型首日适配——对政企信创算力选型，这是两条相互印证的信号。

一、硬件侧：C600 大规模出货 + 安全可靠测评

新华财经报道的核心事实：C600 是沐曦新一代 AI 训推一体旗舰 GPU，已大规模出货，基于国产供应链；MXC600 通过国家安全可靠测评，目标场景包括智算中心、金融、能源、政务。对政企读者，「安全可靠测评」与「国产供应链」是信创采购里常被点名的两项资质，C600 同时具备这两点，意味着它进入了高合规场景的可采购清单。注意区分定位：C600 是数据中心训推一体卡，与摩尔线程「庐山」那类消费级显卡是不同产品线。

  • 产品定位：AI 训推一体旗舰 GPU，数据中心级，非消费级显卡。
  • 合规资质：MXC600 通过国家安全可靠测评，基于国产供应链。
  • 目标场景：智算中心、金融、能源、政务（厂商披露口径）。

二、软件侧：率先完成混元 Hy4 Day 0 适配

据证券时报·e 公司（人民财讯）11 月 21 日 12:49 报道，11 月 20 日腾讯混元正式开源 Hy4，沐曦曦云 C 系列 GPU 率先完成 Hy4 的 Day 0 适配，目前 Hy4 在曦云 C 系列平台上实现高吞吐、低延迟的稳定运行，并在复杂任务与长序列场景下保持优异表现（厂商口径）。「Day 0 适配」的含义是模型开源当天硬件即可运行，这对国产算力生态很关键——硬件能不能用，很大程度取决于主流开源模型是否第一时间适配。结合本站此前对 Hy4 开源的报道，国产 GPU + 国产开源模型的组合正在形成可用闭环。

  • Day 0 适配：模型开源当天硬件即可运行，缩短「有卡没模型用」的空窗。
  • 运行表现为厂商口径（高吞吐、低延迟、长序列优异），具体吞吐数字未公布，需实测。
  • 生态意义：国产 GPU 与国产开源模型首日适配，信创算力闭环更完整。

三、基本面：营收高增与扭亏，供给能力有支撑

新华财经同篇披露的财务数据，为「大规模出货」提供了基本面佐证：沐曦前三季度营收 28.24 亿元、同比增长 128.45%，归母净利润 6.39 亿元实现扭亏；第三季度营收 15 亿元、同比增长 367.12%，归母净利润 2652.71 万元；公司并拟以 1 亿—2 亿元回购股份。营收高增与扭亏说明出货不是纸面消息，而是有真实收入支撑。对采购方而言，厂商的财务健康度与持续供货能力，是选型时除性能外同样要看的维度。

机悟建议：信创算力选型，资质 + 生态 + 供货三看

安全可靠测评是入场券，Day 0 适配是生态信号

  • 高合规场景先核资质：安全可靠测评、国产供应链是信创采购常见硬门槛。
  • 看生态适配：主流开源模型是否 Day 0 适配，决定「有卡能不能立刻用起来」。
  • 看持续供货：厂商财务健康度与出货规模，关系长期运维与扩容。
  • C600 是数据中心训推卡，与消费级显卡区分；机悟可做约 40 分钟信创算力选型评估。
