2026-11-18大模型 · 成本效率

微软一次发布六款专用 AI 模型：编码达 GPT-6.1 Sol 98% 性能，价格仅 40%

11 月 17 日（旧金山），微软在 Ignite 大会发布六款自研 MAI 专用模型，覆盖编码、网络安全、图像与语音：MAI Code 2、Code 2 Flash、Cyber 2 Flash、Image 2.7、Realtime 1、Transcribe 2。微软称旗舰编码模型 Code 2 达到 GPT-6.1 Sol 98% 的性能、价格仅 40%；对 Claude Opus 5.5 则是 96% 性能、5% 成本。同日 OpenAI 发布 GPT-6.2，微软的对标对象已是上一代——专用小模型打旗舰的路线，正在成为大厂共识。

一、六款模型与关键数字

模型定位微软口径
MAI Code 2旗舰编码，跨文件/整项目GPT-6.1 Sol 98% 性能、40% 价格；Opus 5.5 96% 性能、5% 成本
MAI Code 2 Flash日常修复/快速编辑约 Claude Haiku 5.5 性能、20% 价格
MAI Cyber 2 Flash网络安全CyberGym-E2E 92.3%（GPT-6 Astra 91.5%），每任务成本低于 2%
MAI Image 2.7图像生成/编辑Artificial Analysis 图像编辑榜第 1
MAI Realtime 1实时语音微软称优于 GPT-Realtime 2.1
MAI Transcribe 2语音转写专用转写模型

两款编码模型已进 GitHub Copilot（Yahoo/Axios 报道）。微软 AI 负责人 Suleyman 称，公司在自研前沿通用模型上「正取得重大进展」，同时用专用模型以远低于 OpenAI/Anthropic 的成本提供可比性能。

二、数字的口径：促销折扣与自选基准

这些百分比不是无条件成立的。据 Yahoo Tech 梳理 Axios 报道：Code 2 的对照是 4 个企业编码基准的平均，其中 3 个在微软自己的评测平台上跑；成本对比按 50% 促销折扣价计算。也就是说，「5% 成本」里有促销成分，基准选择权也在微软手里。引用时建议带上这两条限定，别把厂商口径当第三方定论。

  • 98%/40% 与 96%/5% 均为微软自述、4 基准平均。
  • 成本含 50% 促销折扣，促销结束后价差会收窄。
  • CyberGym-E2E 92.3% 对 91.5% 是单项安全测试，差 0.8 个百分点，成本差才是重点（低于 2%）。

三、路线之争：专用小模型 vs 通用旗舰

微软这次没有发布「什么都能干」的通用旗舰，而是六款各管一摊的专用模型——编码、网安、图像、语音分开训练、分开定价。逻辑很直白：企业里大量调用是重复的专项任务，用专用模型接住，旗舰只留给少数硬任务，总成本立刻下来。同日 OpenAI 的 GPT-6.2 Sol（日常版）与 Astra（旗舰）分层，走的是同一条路：按任务分层，而不是一个模型打天下。

对私有化部署的启示相同：内网不必只装一个最大的模型。编码、转写、图像各配一个够用的专用模型，显存与电费都能省；关键是先把自己的任务分布统计清楚。

四、采购提醒

  • 厂商对比数字要问三件事：哪些基准、谁跑的、价格含不含促销。
  • 专用模型的「可比性能」限定在特定任务族，跨任务别外推。
  • 本次发布未宣布开放权重，MAI 编码模型经 GitHub Copilot 渠道提供——云端专用模型不等于可私有化。

机悟建议：专用模型路线怎么用到内网

先统计任务分布，再配模型

  • 统计任务分布：把一周的 AI 调用按编码/转写/图像/问答分类，占比最高的任务优先配专用模型。
  • 内网分层部署：日常任务用小模型，硬任务留给大模型，显存与电费双省。
  • 厂商数字带限定引用：基准、评测方、促销折扣三问，写进选型报告。
  • 云端专用模型不等于可私有化：MAI 未开放权重，涉密任务仍要选开源可下载模型。
