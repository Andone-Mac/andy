腾讯混元 Hy Memory 2.0 开源三层记忆系统：30B MoE 记忆模型基准 55.49% 超 Claude Opus 5

2026 年 10 月 16 日，腾讯官方开源混元 Hy Memory 2.0 三层记忆系统：工作、代码、聊天记忆均为 30B 规模 MoE（激活约 3B），SDK 与 MemHub 上 GitHub、权重上 Hugging Face。其记忆基准宏平均 55.49%，首次超过 Claude Opus 5 的 54.62% 与 DeepSeek V4.1 Flash 的 53.64%；LoCoMo 单问题 token 降 39.3%。对政企而言，这意味着长程记忆能力可以完整跑在内网、数据不出域——机悟可以用本地化部署帮你完成这次「记忆层加装」。

三层记忆全部开源：工作、代码、聊天一次给齐

Hy Memory 2.0 把「记忆」拆成三层独立模型：工作记忆 Hy-Memory-30A3B 负责短期任务上下文，代码记忆 Hy-Memory-Code-30B-A3B 面向代码库理解，聊天记忆 Hy-Memory-Chat-30B-A3B 沉淀长期对话偏好。三层统一 30B 规模、MoE 激活约 3B——总参数大、激活小，意味着本地推理硬件上的吞吐压力远小于同规模稠密模型。SDK 与 MemHub 上 GitHub、权重上 Hugging Face、全部开源，政企可以按自身数据边界选择「只用开源 SDK」或「权重全量内网部署」，记忆资产沉淀在客户自己手里。

  • 工作记忆 Hy-Memory-30A3B：MoE 架构、激活约 3B，负责短期任务上下文；
  • 代码记忆 Hy-Memory-Code-30B-A3B：面向代码库理解；
  • 聊天记忆 Hy-Memory-Chat-30B-A3B：沉淀长期对话偏好；
  • 开源范围：SDK 与 MemHub 上 GitHub，模型权重上 Hugging Face。

首个可与旗舰闭源对比的「记忆层」基准

此前「记忆能力」基本停留在各家宣传口径，缺乏可对比的基准数据。这次给出的数字是：记忆基准宏平均 55.49%，超过 Claude Opus 5 的 54.62% 与 DeepSeek V4.1 Flash 的 53.64%；MemoryArena 得分 55.31%，领先 EverOS 10.2 个百分点；CodeMemoryBench 问答 64.2%；LoCoMo 72.6%，单问题 token 由 1159 降至 703、降幅 39.3%。对选型方的含义很直接：「记忆」开始和「推理」一样，成为可以用基准数字横向比较的采购维度，而开源模型第一次在这个维度上站到了旗舰闭源之上。

第二层含义在采购流程：今后评估供应商的记忆能力，政企可以要求对方提供同一口径、可复现的基准分数，甚至在自己的数据上跑本地复现。宏平均 55.49% 给记忆层定了一个「天花板」参照——开源方案在政企长程记忆需求上第一次具备了进入短名单的资格，而不只是「便宜但能力存疑」的备选。

对政企的含义：记忆层数据不出域

记忆数据是政企 AI 项目里最敏感的资产之一——对话历史越长，沉淀的业务细节越多。记忆层部署在内网，意味着这份资产从生成、存储、检索到删除的全生命周期都在客户自己的合规边界之内，与等保三级、密评的要求天然对齐；而云 API 的记忆服务把数据驻留在服务商侧，「数据不出域」很难真正落实。叠加 token 降 39.3%，云客户账单直接下降，本地客户吞吐与响应时长改善。与之同场发布的新一代视觉理解「快思考」模型（基于 HY-2.0 LLM，SFT+RL 加 On-policy Distillation 训练），与三层记忆组合后，视觉输入、快速推理、长程记忆检索的完整推理链路都可以跑在内网——对已本地部署混元的客户，这次发布相当于给既有部署「加装」了记忆组件。

  • 硬件基线/实测：llama.cpp + 7900 XTX 24G 单机 55+ token/s；UOS 25/麒麟 V10/欧拉适配；等保三级/密评/备案材料包交付；三年 TCO 约为云 API 1/6~1/8；
  • 接入方式：MemHub 兼容 Hermes 等 10 种主流 AI 工具，记忆层可作为独立组件接入内网既有 Agent 栈。

机悟的建议：把「记忆层」写进采购评估表

开源记忆层是本地化部署补长程记忆能力的直接选项，不必等云账单涨上来再谈迁移。

  • 记忆先行：将「记忆能力基准（可复现口径）」「记忆数据驻留位置」「与既有 AI 工具的兼容性」写入大模型采购评估表；
  • 本地先行：记忆层权重可全量内网部署，数据生命周期留在自有合规边界内，等保三级/密评天然对齐；
  • 成本先行：LoCoMo 单问题 token 降 39.3%，长对话场景直接省成本，与本地部署 TCO 一并测算；
  • 试点先行：先选一条业务线做聊天记忆试点，验证长程任务效果与响应时长后再推广。
