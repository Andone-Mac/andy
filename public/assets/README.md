# 资料下载 · 维护说明

网站「关于我们 → 资料下载」区的文件都在这个目录。**对外公开版本才能放这里**
（不含客户信息、项目细节、内部报价）。

## 新增一份资料（两步）

1. 把文件拷进本目录（支持 `.pdf / .ppt(x) / .doc(x) / .xls(x) / .zip / .rar`）
2. 在 `siteV5/` 目录执行：

   ```bash
   python3 tools/gen_downloads.py
   ```

   脚本会扫描本目录、把清单写进 `about.html`，并提示哪些新文件建议补中文标题。

3. 想显示更好看的中文标题/说明，编辑本目录的 `manifest.json`：

   ```json
   {
     "文件名.pdf": { "t": "标题", "d": "一句话说明", "date": "2026-10" }
   }
   ```

   改完再跑一次脚本即可。`s`（文件大小）由脚本自动读取，不用手填。

## 删除一份资料

把文件从本目录删掉，再跑一次脚本——清单会自动同步。

## 注意

- 大文件会进入网站部署包（每次访问者点下载才消耗流量），建议单个文件 ≤ 20MB；
  超大的（如视频）更适合放网盘，页面里放外链。
- 文件名尽量用中文短名，避免空格与特殊符号（脚本会自动做 URL 编码）。
- 部署：`siteV5/` → `site/` → `site-deploy-git/public/` → git push（Render 自动发布）。
