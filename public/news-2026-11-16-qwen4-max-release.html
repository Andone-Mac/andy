中国旗舰大模型正式换代：阿里 Qwen4-Max 单任务费用降 58%，前端编程盲测冲进全球前六

11 月 16 日上午，阿里把 11 月 11 日先行开放的限时预览版转正，正式发布新一代基座大模型 Qwen4-Max。这一代最突出的变化不是把参数堆得更高，而是把「完成一个任务要花多少钱」压了下来：总参数仍是 2.4 万亿，但每个 Token 实际激活的参数从 95B 降到 71B，配合稀疏注意力与缓存命中降价，官方口径单任务平均费用较上代下降 58%。对要把大模型接进生产流程的企业来说，这意味着同样的智能体与编程任务，账单可能直接砍掉一半多。本文梳理这次正式版的架构、跑分、定价与落地实证，并交代哪些数字是官方自报、哪些已有第三方榜单佐证。

一、这次到底发布了什么

与 11 月 11 日的限时预览版不同，此次是正式版本接入千问 AI 平台对外提供 API 服务。用户可通过阿里 Token Plan 调用，或在千问办公、Qoder、千问 App、Qwen Studio 等应用中直接体验。模型支持联网搜索、工具调用、结构化输出，兼容 OpenAI 与 Anthropic 两种 API 格式，输入模态覆盖文本、图像与视频。

  • 总参数 2.4 万亿（2.4T），每个 Token 激活 71B，较上代 95B 减少约 25%（本刊计算）。
  • 原生视觉理解，100 万 Token 上下文窗口。
  • 稀疏 MoE 架构，围绕 Attention、Residual、Embedding 三个方向做了系统性调整。
  • 另有 328B 的 N-gram Embedding 参数，以查表方式引入局部 token 模式，不怎么吃计算量。

二、省钱省在哪：架构与思考效率

Qwen4-Max 采用基于 Qwen 稀疏注意力（QSA）的全新 MoE 架构：每四层里三层用 Gated DeltaNet 把历史信息压缩成固定大小的状态，剩下一层留给 QSA 按块挑选眼下用得上的上下文，以降低长序列的注意力开销；训练期叠了四条并行门控残差流稳住梯度。官方称整轮训练没出现过一次 loss 尖峰。思考效率的提升是这次降本的核心。

四、定价与落地实证

计费项（每百万 Token）国内海外
输入10 元1.5 美元
输出30 元4.5 美元
缓存命中输入0.5 元（约为输入价的 1/20）下调约 70%
  • 汽车制造：单个工件加工编程的人工用时从约 475 分钟降到二十几分钟，用时减少约 95%（不同报道口径为 24–26 分钟）。
  • 游戏开发：可调用 Blender 等专业工具，一句话生成 3D 游戏。
  • 金融投研：可调用 90 个 MCP 专业工具，产出 Excel 底稿与 PPT 报告。
  • 科学发现：连续 48 小时自主运行，从 270 万个候选分子中合成一种新型冷却液材料；针对阿尔兹海默症靶点经 454 次工具调用优化出 24 个候选分子，优选分子结合亲和力较起点提升约 3.6 倍。

给读者一个直观换算：缓存命中价 0.5 元/百万 Token，100 元预算约可命中 2 亿 Token（本刊计算）。这正是几十轮工具调用、百万上下文反复翻看的长任务最省钱的地方——塞进去过的底稿和代码库，后面重复读取基本只花零头。

五、开源与边界

阿里未将 Qwen4-Max 本体开源，但表示 Qwen4 系列中的中小尺寸模型将陆续开源发布，沿袭同源技术路线。这与本站 11 月 11 日那篇「Qwen4 官宣、预览版先上线」的预告一脉相承——今天兑现的是正式版与降本承诺。对企业选型而言，旗舰降本利好云端长程任务，而真正要数据不出内网的场景，仍要等中小尺寸开源后再评估本地部署可行性。

机悟建议：旗舰降本，企业该怎么接

把「单任务费用」当成新的选型指标

  • 长程智能体、编程、科研这类复杂任务，优先评估 Qwen4-Max 的 Cost per Task，而不是只看每百万 Token 单价。
  • 高频重复读取同一份底稿/代码库的场景，把缓存命中率做上去，账单差距会被进一步放大。
  • 涉及敏感数据、要求数据不出内网的业务，等 Qwen4 中小尺寸开源后再做本地化对照，别急着把旗舰搬上云。
  • 官方自报跑分与第三方榜单分开看；落地前用自己的真实任务集复跑一遍，再决定切换。
