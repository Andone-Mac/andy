2026-11-20开源模型 · 结构化抽取

中国千问底座出海：Cloudflare 开源 Clairic 27B/9B，Apache 2.0、输出免费

11 月 18 日，Cloudflare 新成立的 Workers AI Superintelligence 团队开放了 Clairic 与 Clairic-flash 两款模型的权重（官方博客当日发布，Apache 2.0）。值得中国读者注意的是底座：本刊查 Hugging Face 模型卡的 base_model 字段，27B 的 Clairic 基于 Qwen/Qwen3.8-27B、9B 的 Clairic-flash 基于 Qwen/Qwen3.5-9B——一款美国公司做的垂直抽取模型，底座来自中国千问。本篇讲三件事：底座与规格、它擅长的结构化抽取、以及「只收输入、按 pass 重发」的计费坑与私有化门槛。

一、底座与规格：两个版本都来自千问

本刊查 Hugging Face API 与模型卡：Cloudflare/clairic 的 base_model 为 Qwen/Qwen3.8-27B、license 为 apache-2.0、pipeline 为 image-text-to-text；Cloudflare/clairic-flash 的 base_model 为 Qwen/Qwen3.5-9B、license 同为 apache-2.0，模型卡自述「9B multimodal model」。权重体积经本刊对仓库文件逐项求和：clairic 约 55.9GB（19 个文件）、clairic-flash 约 19.6GB（5 个文件）。两款都带 custom-code 标签，自托管需运行仓库自带代码。

版本底座（base_model）权重体积许可
Clairic（27B）Qwen/Qwen3.8-27B约 55.9GB（19 文件）Apache 2.0
Clairic-flash（9B）Qwen/Qwen3.5-9B约 19.6GB（5 文件）Apache 2.0
  • 底座是千问、上层是 Cloudflare 的抽取微调——这是「中国底座 + 海外垂直应用」的一个具体样本，引用时把底座与微调方分开署名。
  • Apache 2.0 意味着可商用、可私有化，但仍需遵守仓库 custom-code 的运行要求与 Apache 2.0 的署名/免责条款。

二、它做什么：结构化抽取 + 置信度

Clairic 定位是「System One 式」抽取模型：给定一段 state（文本/JSON）加可选图片，再给一组字段规格，它输出强类型的值——文本、数字、日期、列表、空值、估计值，并附带置信度、空值概率与分位数（官方文档与 README）。典型场景是发票、合同、表单这类「从非结构化输入里抽结构化字段」的活。它支持多模态，每个请求最多 4 张图片（单张 4MiB、合计 8MiB）。

  • 自托管延迟（官方自述，完整 HTTP 响应口径）：文本字段 Clairic 中位 358ms / p95 736ms，flash 155ms / 328ms；图像字段 Clairic 453ms / 976ms，flash 305ms / 605ms。
  • 官方明确这是方向性自述，尚无公开抽取基准；官方文档仍把模型标为 preview。引用延迟与能力时带上「官方自述、preview」限定。
  • 自托管入口 load_release_model / systemone，需 Python 3.11+ 与 xgrammar 做 schema 约束（README）。

三、计费与部署：只收输入、按 pass 重发

云端计费有个反直觉点：Clairic 把媒体输入折算成 input token 按输入价计费，输出 token 不收费（官方文档）。但每个 text 字段单独走一个 pass，每个 pass 都重发完整 state 与全部图片并各计一次费，usage.passes 报告 pass 数——字段越多，输入费越高。官方定价页口径：Clairic 27B 促销价 0.10 美元/百万输入（9091 neurons）至 2026 年 12 月 1 日，之后 0.24 美元/百万输入（21818 neurons）；flash 恒为 0.10 美元/百万输入。Workers AI 平台价为 0.011 美元/1000 neurons，免费额度 10000 neurons/天（00:00 UTC 重置）。

版本促销价（至 12-1）12 月后标准价
Clairic 27B$0.10/百万输入$0.24/百万输入
Clairic-flash 9B$0.10/百万输入$0.10/百万输入

算一笔账（本刊计算，假设 state + 图片合计约 2000 token）：抽 4 个 text 字段 = 4 个 pass × 2000 = 8000 计费输入 token，促销档约 $0.0008、12 月后约 $0.00192。图片 token 按官方规则约 (宽/32)×(高/32)+2：一张 1024×1024 图约 1026 token、256×256 约 66 token。免费额度 10000 neurons/天在促销档约合 110 万输入 token/天（本刊计算）。私有化侧：Apache 2.0 + custom-code，9B flash 权重 19.6GB 单张 24GB 卡可载，27B 55.9GB 需更大显存或多卡；这是「能装下」的口径，速度以实测为准。

机悟建议：抽取类任务先看底座与计费坑

千问底座可私有化，pass 重发会放大输入费

  • 底座与微调分开看：Clairic 基于千问 Qwen3.8-27B / Qwen3.5-9B，Apache 2.0 可商用可私有化。
  • 计费坑：每个 text 字段一个 pass、每 pass 重发 state 与全部图片，字段多则输入费翻倍，先估 pass 数再报价。
  • 能力限定：官方自述延迟、尚无公开抽取基准、文档仍标 preview，选型要自己跑样本验证。
  • 9B flash 19.6GB 单卡可载、27B 需多卡；内网抽取场景机悟可约 40 分钟评估部署与成本。
